# Portfolio

Personal portfolio site for Simpi Singh — Full-Stack Software Engineer.

Built with [Next.js](https://nextjs.org) (App Router) + TypeScript as a fully static site, deployed on Vercel.

## Development

```bash
npm install
npm run dev        # http://localhost:3000
```

## Scripts

| Command                | What it does                           |
| ---------------------- | -------------------------------------- |
| `npm run dev`          | Start the dev server                   |
| `npm run build`        | Build the static site into `out/`      |
| `npm run lint`         | Lint with ESLint                       |
| `npm run typecheck`    | Type-check with TypeScript             |
| `npm run format`       | Format all files with Prettier         |
| `npm run format:check` | Check formatting without writing files |

Preview the production build locally with `npx serve out`.
